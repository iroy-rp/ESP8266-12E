# Lámpara Inteligente con ESP8266 y Alexa

Proyecto basado en el ESP8266-12E para controlar una lámpara mediante comandos de voz utilizando Amazon Echo Dot (Alexa).

## Características

- Encendido y apagado por voz.
- Control inalámbrico mediante Wi-Fi.
- Basado en ESP8266-12E.
- Compatible con Amazon Alexa.

## Objetivo

Compartir el hardware, software y la documentación necesaria para que cualquier persona pueda construir su propia lámpara inteligente.

## Tecnologías utilizadas

- ESP8266-12E
- Arduino IDE
- Wi-Fi
- Amazon Alexa
